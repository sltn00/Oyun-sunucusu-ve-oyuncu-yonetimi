# Oyun-sunucusu-ve-oyuncu-yonetimi
Bu proje çok oyunculu oyunlarda oyuncuların ELO puanlarını, maç istatistiklerini, envanterlerini, katıldıkları turnuvaları ve görev başarımlarını yönetmek için tasarlanmış bir veritabanı sistemidir. Sistem üzerinden oyuncuların performansları takip edilmekte, hile/şikayet durumları kontrol edilmektedir ve anlık sıralamalar listelenmektedir.
